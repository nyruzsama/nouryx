# 🎓 Summative Reviewer & Gimkit Game Arena

A unified, gamified web application and educational reviewer for Senior High School summative examinations.

## 🚀 Live Web Applications

1. **`index.html`**: The Central Summative Reviewer Hub
   - 🗣️ **Mabisang Komunikasyon** (Aralin 3 & 4: 5 Elemento, Anyo, Antas, Privacy, at Konteksto)
   - 🔬 **General Science** (Weeks 5 & 6: Simple Machines, Levers, Pascal's Principle, Archimedes' Principle)
   - 🧮 **General Mathematics** (Lesson 1: Payroll, Article 87 Overtime, 11 PH Taxes, 2025 Deductions + Weeks 6-8 Percentages, Nature Patterns & Sequences)
   - 📐 **Finite Mathematics 1** (Tessellations, Golden Ratio, Fractals, Matrices)
   - 📜 **PKLP (Kalinangang Pilipino)** (Dimensiyon ng Buhay, Kabilang-Buhay & Manunggul Jar, Katutubong Lunas & 10 Halamang-Gamot, at Sinkretismo)
   - 🎯 **27 Interactive Quizzes** with immediate feedback and sound synthesis.

2. **`gengen.html`**: Gimkit-style Gamified Question Arena
   - ⚡ **Classic Kit Arena**: In-game upgrade shop (cash per question, streak multipliers, shields, insurance).
   - 🌋 **Floor is Lava Mode**: Rising lava survival challenge.
   - 👾 **Boss Raid Mode**: Challenge *"The 2025 BIR Tax Auditor"* and *"Ang Sinaunang Babaylan"*.
   - ⏱️ **Time Blitz Mode**: 120-second rapid sprint.

## 📦 How to Deploy on GitHub Pages

1. Push the contents of this folder to a GitHub repository:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Summative Reviewer & Gimkit Arena"
   git branch -M main
   git remote add origin <your-github-repo-url>
   git push -u origin main
   ```
2. In your GitHub repository:
   - Go to **Settings** > **Pages**.
   - Under **Build and deployment** > **Branch**, select `main` and `/ (root)`.
   - Click **Save**.
3. Your site will be live across all mobile devices and desktop computers!
